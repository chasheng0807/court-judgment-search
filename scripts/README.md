# 案例检索报告生成器（scripts/）

将裁判文书（.docx / .txt）+ 检索要求，按「案例检索报告」模板的单元格排版自动生成 Word 文档。

## 依赖
- Python 3 + python-docx（Anaconda 自带；其他环境执行 pip install python-docx）

## 用法
```bash
python generate_case_report.py 文书1.docx 文书2.docx --req "混同用工、连带责任" --out 报告.docx
```

## 同名笔记（可选，用于精细控制字段）
为每份文书放一个同名 .md（如 （2025）陕01民终18188号.md）：
```
争议焦点：西安某公司、北京某公司是否构成混同用工，以及应否支付徐某解除补偿金、工资及各项待遇？
可参考观点：
认定混同用工应穿透审查实际用工管理，而非仅凭签约主体。
二审法院以入职时间证据不足驳回部分诉请，提示劳动者留存工牌、入职表等原始证据。
```
- 争议焦点：优先采用，作为精简问句
- 可参考观点：多行要点，自动以 1、2、3、 编号

## 输出格式（对齐模板）
- 争议焦点：精简为一句
- 裁判观点：按文书层级拆为「再审申请人意见 / 一审法院查明事实 / 一审法院裁判观点 / 二审法院裁判观点 / 再审审查裁判观点」等子段，标签行加粗单列
- 本案可参考观点：1、2、3、 序号分点

## 参数
- docs：裁判文书路径（可多个）
- --req / --req-file：检索要求（填入关键词行）
- --template：模板 docx 路径（默认指向本地模板，可改为自己的模板）
- --out：输出 docx 路径
