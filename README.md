# 裁判文书检索资源库

> 面向法律检索初学者，整理裁判文书的检索入口、数据源与实用技巧。本仓库是持续补充的资料库，欢迎按需扩展。

## 一、什么是裁判文书
- **裁判文书** = 法院在审理案件后作出的判决书、裁定书、调解书、决定书等正式法律文书。
- 我国实行**裁判文书上网公开**制度，但涉国家秘密、个人隐私、未成年人犯罪、调解结案等依法不公开。

## 二、官方检索入口（首选）
- **中国裁判文书网** https://wenshu.court.gov.cn
  - 全国法院生效裁判文书的官方统一公开平台
  - 支持组合检索：案由、法院名称/层级、当事人、文书类型、审判程序、裁判日期、全文关键词
  - 提示：访问高峰可能需登录/验证码，建议错峰检索

## 四、检索技巧
1. 先定**案由**（如"买卖合同纠纷""机动车交通事故责任纠纷"），比全文关键词更准。
2. 用**法院层级 + 地域**缩小范围（如"北京市高级人民法院"）。
3. 用**裁判日期**锁定时间窗口。
4. 关键词组合：核心事实 + 争议焦点 + 法条。
5. 善用**指导性案例 / 典型案例**作为类案参考。

## 五、注意事项
- 不是所有文书都上网；上网文书也可能脱敏（隐名处理）。
- 引用裁判文书作依据时，务必核对案号、原文与生效状态。
- 遵守各平台使用条款，勿批量爬取或滥用。
