# 案例 05 ｜ 珠海劳动仲裁案（部分被申请人免于连带责任）

- **审理机关**：珠海市劳动人事争议仲裁院
- **来源**：珠海市劳动人事争议仲裁院 裁决书（2025）
- **基本事实**：申请人与被申请人一签订劳动合同建立劳动关系；被申请人二、三、四曾向申请人发放部分月份工资，被申请人四向申请人出具工作证并加盖公章，《工资调整表》有被申请人一、二、四的工作人员或负责人签字确认。
- **裁判结果**：被申请人二、四对被申请人一的支付义务承担**共同支付责任**；**被申请人三无需承担共同支付责任**。
- **仲裁委不支持连带的理由**：参照《最高人民法院关于审理劳动争议案件适用法律问题的解释（二）》第三条第二款，认定混同用工应以"不同法人主体是否对劳动者构成混同用工"为依据。仅银行流水显示被申请人三发放部分月份工资，不足以证明申请人接受被申请人三的用工管理，亦不足以证明申请人为被申请人三提供劳动，故对被申请人三构成混同用工的主张不予采纳。
- **关键词**：劳动仲裁、部分连带、代发工资不足以证成混同
- **来源链接**：https://zhrsj.zhuhai.gov.cn/attachment/0/422/422378/3862057.pdf
