# 裁判规则归纳 ｜ 法院为何"不支持"混同用工企业承担连带责任

> 基于本目录 7 个案例与《劳动争议司法解释（二）》第 3 条，归纳法院不予支持关联企业就混同用工承担连带责任（或共同责任）的典型情形。

## 一、核心法律依据
《最高人民法院关于审理劳动争议案件适用法律问题的解释（二）》法释〔2025〕12号 第三条（2025-09-01 施行）：
1. 已订书面劳动合同 → 按合同确认劳动关系；
2. 未订合同 → 按用工管理行为等综合确认；
3. 符合第 2 款情形的，劳动者请求关联单位**共同承担支付劳动报酬、福利待遇等责任**，原则上支持（但单位间有约定且经劳动者同意的除外）。

**推论**：连带责任并非"只要有关联 + 交叉用工就自动成立"，其适用有明确边界。

## 二、法院不支持连带责任的四类典型情形

### 1. 混同用工事实未证成（证据不足）
- 单某案 (2025)粤0114民初2738号：代发工资可由集团内委托代发解释，微信沟通不具长期性、固定性，合同签订/考勤/解除均指向签约公司 → 连带责任未获支持。
- 珠海仲裁案：仅银行流水显示某被申请人发放部分月份工资，不足以证明其进行用工管理 → 该被申请人免责。
- **举证要点**：须证明"同时接受多家管理、工作地点相同、内容交叉"，零散的代发工资/偶发沟通不足以证成。

### 2. 劳动关系可明确区分
- 秦某加班费案：二审认为劳动关系能够区分时，不必然适用连带责任。
- 谢某某案 (2018)粤03民终13950号：有书面合同则按合同确定单一主体，二倍工资不对非签约单位。
- 王某快递案：工伤保险购买、认定申请、工资发放、解除协议均指向单一公司 → 不支持多家均摊。

### 3. 请求项目不属于共同责任范围（惩罚性赔偿除外）
- 罗某案（湖北高院典型案例）：混同用工中关联公司共同承担的是"劳动报酬、福利待遇"；**未签劳动合同二倍工资系惩罚性赔偿，不在共同责任范围**，故某钢构公司不连带。
- 谢某某案同理：二倍工资差额不支持向非签约单位主张。

### 4. 混同用工"不必然"连带，劳动者可择一主张
- 甲公司雇主责任险案（江苏法院）：工伤认定、仲裁已确认用人单位为乙公司；混同用工并不必然适用连带责任，劳动者可选择主张权利的对象；甲公司非负赔偿责任人则无保险利益。

## 三、反面对照：何时"支持"连带责任 / 共同责任
- 解释二第 3 条第 2 款：未订合同且符合"用工管理行为"标准的，关联单位对劳动报酬、福利待遇**共同承担**。
- 农安法院案、珲春法院案：核心人员、用工管理、业务经营高度混同 → 判决关联公司**承担连带责任 / 共同赔偿**。
- 珠海仲裁案本身也支持了被申请人二、四的共同责任，仅剔除证据不足者。
- **关键分野**：是否"真正构成混同用工" + 请求项目是否属共同责任范围。

## 四、实务提示
1. **对劳动者**：留存工作群记录、考勤、工资流水、社保缴纳、解除协议等，证明"实际用工管理主体"；主张连带时明确所依据的项目（报酬/福利 vs 惩罚性赔偿）。
2. **对企业**：混同用工不能规避责任，但规范签约、明确单一用工主体，可避免被认定为混同进而导致连带；出借资质、代发工资等"轻接触"通常不必然导致连带。
3. **解释二生效后**（2025-09-01 起）：裁判规则更统一，"以用工管理行为为核心"成为主流标准。
