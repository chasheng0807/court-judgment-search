# 混同用工中"法院不支持企业承担连带责任"案例库

> 本目录收录**法院未支持 / 未予认定关联企业就混同用工承担（连带）责任**的公开司法案例与裁判观点，供研究、检索与类案参考。

## 法律背景（关键依据）
《最高人民法院关于审理劳动争议案件适用法律问题的解释（二）》法释〔2025〕12号 第三条（2025-09-01 施行）：
- 已订书面劳动合同 → 按合同确认劳动关系；
- 未订合同 → 按用工管理行为等综合确认；
- 符合未订合同情形的，劳动者请求关联单位**共同承担支付劳动报酬、福利待遇等责任**，原则上支持（但单位间有约定且经劳动者同意的除外）。

> 由此推导：法院"不支持连带责任"通常出现在——① 混同用工事实未证成；② 劳动关系可明确区分；③ 请求项目不属于共同责任范围（如二倍工资等惩罚性赔偿）；④ 已订书面劳动合同、劳动关系明确，不当然产生关联企业连带责任。
