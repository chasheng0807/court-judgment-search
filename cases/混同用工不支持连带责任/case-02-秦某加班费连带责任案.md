# 案例 02 ｜ 秦某诉工业公司加班费连带责任案

- **审理机关**：二审法院
- **来源**：中工网 / 法治网《关联公司混同用工谁是"东家"》（2022-07-29）
- **基本事实**：关联企业交叉轮换使用劳动者，工作内容交叉重叠。
- **裁判结果**：对秦某要求工业公司对加班费承担**连带赔偿责任**的诉求，**二审法院不予支持**。
- **法院观点**：虽然关联企业在劳动关系主体无法确认时可承担连带责任，但**前提是劳动关系主体无法确认**；如果劳动关系能够区分，则**不必然适用连带责任**。
- **关键词**：加班费、劳动关系可区分、不必然连带
